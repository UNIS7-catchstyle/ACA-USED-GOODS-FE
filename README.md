# 시작 가이드

## Requirements

For building and running the application you need :

- Node.js 20.19.0
- npm 11.11.0
- React 19.1.1
- Vite 7.3.2

## Installation

```bash
$ git clone https://github.com/UNIS7-catchstyle/ACA-FE
$ cd ACA-USED-GOODS-FE
```

```bash
$ npm create vite@7
$ npm install
$ npm run dev
```
